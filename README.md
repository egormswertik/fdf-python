## Описание

Программа для визуализации трёхмерной каркасной (wireframe) модели поверхности по карте высот в изометрической проекции (по мотивам проекта FdF школы 42).

## Формат карты

Текстовый файл `.fdf`, где каждая строка задает ряд точек (координата Y), позиция числа в строке — координату X, а само число — высоту Z.

## Структура проекта

- `fdf/` — исходный код пакета
- `maps/` — тестовые карты высот
- `tests/` — автоматические тесты
